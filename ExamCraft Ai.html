DS • Unit 3 High Probability

Binary Search Trees & Traversal

BST insertion, deletion, and Inorder, Preorder, and Postorder recursive traversal procedures.

Quick Recall:

  • BST Inorder traversal always yields sorted ascending data.
  • Time complexity: Average $O(\log n)$, Worst $O(n)$.
  • Left subtree keys are strictly less than root; right keys are greater.
  • Recursive implementations rely entirely on the system call stack.
COA • Unit 2 7M Question

Addressing Modes & CPU Registers

Immediate, Direct, Indirect, Register Indirect, and Indexed addressing mode calculations.

Quick Recall:

  • Effective Address (EA) = Content of Pointer / Base + Displacement.
  • Direct addressing specifies the operand memory address explicitly in the instruction code.
  • Immediate mode encodes constant values directly within the instruction word.
  • Indirect mode requires an extra memory access cycle to resolve the final target address.
DBMS • Unit 4 Core Topic

Normalization: 1NF, 2NF, 3NF & BCNF

Functional dependencies, removing insertion/deletion anomalies, and lossless decomposition.

Quick Recall:

  • 1NF enforces atomic cell values and eliminates repeating groups.
  • 2NF removes Partial Functional Dependencies from composite keys.
  • 3NF eliminates Transitive Dependencies ($X \rightarrow Y$, $Y \rightarrow Z$).
  • BCNF is a stricter version of 3NF where every determinant must be a candidate key.
DS • Unit 1 Essential

1D/2D Arrays & Sorting Algorithms

Matrix operations, string handling functions, Bubble Sort, Insertion Sort, and Binary Search implementations in C.

Quick Recall:

  • Bubble sort compares adjacent elements with $O(n^2)$ worst-case time complexity.
  • Binary search requires a sorted array with logarithmic $O(\log n)$ efficiency.
  • Arrays store elements in contiguous memory locations for direct index access.
  • Strings in C are null-terminated character arrays ending with \0.
OS • Unit 2 Numerical 7M

CPU Scheduling Algorithms

Non-preemptive and preemptive scheduling: FCFS, SJF (Shortest Job First), Priority Scheduling, and Round Robin (RR) with quantum time.

Quick Recall:

  • Turnaround Time = Completion Time − Arrival Time.
  • Waiting Time = Turnaround Time − Burst Time.
  • Round Robin uses fixed time slices (quantum) to ensure fair time-sharing.
  • SJF provides the minimum average waiting time but requires prior burst time knowledge.
Math • Unit 1 Core Unit

Set Theory & Equivalence Relations

Venn diagrams, set identities, Cartesian products, and properties of binary relations (Reflexive, Symmetric, Transitive).

Quick Recall:

  • An Equivalence relation satisfies Reflexive ($aRa$), Symmetric ($aRb \implies bRa$), and Transitive properties.
  • Principal Inclusion-Exclusion principle calculates set cardinalities: $|A \cup B| = |A| + |B| - |A \cap B|$.
  • Cartesian product $A \times B$ yields the set of all ordered pairs $(a, b)$.

Last-Moment BCA & B.Sc IT Question Bank

The most repeated university theoretical & code-tracing questions.

1. Explain Call by Value vs Call by Reference in C with pointer diagrams. (7 Marks)

Answer: Call by Value passes copies; alterations inside the function do not affect original values. Call by Reference passes pointer addresses (int *x), modifying actual memory locations directly.

Exam Tip: Always provide the classic void swap(int *a, int *b) code snippet for full marks.

2. What are the four essential conditions for Deadlock in Operating Systems? (7 Marks)

Answer: Coffman Conditions: (1) Mutual Exclusion, (2) Hold and Wait, (3) No Preemption, and (4) Circular Wait. If any one condition is broken, deadlock cannot occur.

3. Differentiate between Primary Key, Unique Key, and Foreign Key in SQL. (7 Marks)

Answer: Primary Key uniquely identifies a record and CANNOT accept NULLs. Unique Key enforces uniqueness but permits one NULL. Foreign Key links child table to parent table ensuring referential integrity.

4. Describe Von Neumann computer architecture and explain the Instruction Fetch-Decode-Execute cycle. (14 Marks)

Answer: Von Neumann architecture features a unified memory storing both program instructions and data, connected via system buses to the Control Unit, ALU, and Registers (PC, MAR, MBR, IR). The cycle fetches instructions into IR, decodes them via CU, and executes them in the ALU.

Exam Tip: Draw the block diagram showing memory unit connected to CPU via address and data buses.

5. Explain Database Normalization (1NF, 2NF, 3NF) with suitable examples and anomaly explanations. (14 Marks)

Answer: Normalization eliminates insertion, update, and deletion anomalies. 1NF requires atomic cell values; 2NF removes partial functional dependencies; 3NF removes transitive dependencies where non-key attributes depend on other non-key attributes.

6. What is virtual memory? Explain Paging and Demand Paging mechanism in Operating Systems. (7 Marks)

Answer: Virtual memory separates logical memory from physical RAM. Paging divides memory into fixed-size blocks (pages and frames) mapped via Page Tables. Demand paging loads pages into physical memory only when referenced during execution.

7. Prove that (p → q) ≡ (¬p ∨ q) using truth tables and algebraic laws in Discrete Mathematics. (7 Marks)

Answer: Construct a 4-row truth table for propositions p and q. Columns for p, q, p → q, ¬p, and (¬p ∨ q) will demonstrate identical truth value outputs across all input combinations.
